FinancePulse Data Analysis

A comprehensive Financial Data Analysis project developed using Python, Pandas, NumPy, MySQL, Matplotlib, Seaborn, and Power BI. The project focuses on cleaning, analyzing, and visualizing financial data to generate meaningful business insights through interactive dashboards and analytical techniques.

Project Overview

This project analyzes financial performance using Python, SQL, and Power BI. It provides insights into revenue, profit, operational costs, regional performance, business units, product categories, customer ratings, and payment methods through interactive reports and visualizations. The project demonstrates data cleaning, preprocessing, exploratory data analysis (EDA), SQL analysis, data visualization, and dashboard development.

How to Use

Download or clone this repository.

Open FinancePulse.ipynb using Jupyter Notebook.

Run the notebook to perform data cleaning, preprocessing, and exploratory data analysis.

Import the dataset into MySQL and execute the SQL queries available in financepulse_queries.sql.

Open FinancePulse.pbix using Power BI Desktop.

Refresh the dataset if required.

Explore the dashboard using the available filters and slicers.
