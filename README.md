FinancePulse Data Analysis

A Financial Data Analysis project developed using Python, Pandas, NumPy, MySQL, Matplotlib, Seaborn, and Power BI. The project analyzes financial transaction data to generate meaningful business insights through interactive dashboards, visualizations, and key performance indicators (KPIs).

Project Overview

This project analyzes financial performance using Python, SQL, and Power BI. It provides insights into revenue, profit, operating costs, regional performance, business units, product categories, payment methods, and customer ratings through interactive reports and visualizations. The project demonstrates data cleaning, preprocessing, exploratory data analysis (EDA), SQL analysis, data visualization, and dashboard development.

How to Use

Download this repository as a ZIP file or clone it from GitHub.

Open FinancePulse.ipynb using Jupyter Notebook.

Run the notebook for data cleaning, preprocessing, and exploratory data analysis.

Import the dataset into MySQL and execute financepulse_queries.sql.

Open FinancePulse.pbix using Power BI Desktop.

Refresh the dataset if required.

Explore the dashboard using the available filters and slicers.
